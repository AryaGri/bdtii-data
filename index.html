Базы данных PostgreSQL

  1. Создайте пустую базу: в pgAdmin правой кнопкой по Databases, Create, Database (имя autoservice), или командой CREATE DATABASE autoservice;
  2. Откройте Query Tool для этой базы (в DBeaver: SQL-редактор).
  3. Нажмите «Копировать SQL» (или скачайте файл и откройте его), вставьте скрипт в редактор и выполните (F5 в pgAdmin, Alt+X в DBeaver).
