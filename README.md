# Данные к рабочей тетради БДиТИИ

Страница с учебными данными к рабочей тетради «Интеллектуальный мегаполис. Потенциал» (ИТ-класс, направление «Большие данные и технологии ИИ»).

- `index.html` — сама страница;
- `data/` — SQL-скрипты учебных баз, CSV-файлы и гистограммы;
- `data/vars/` — данные к задачам 2.2 по вариантам (A1…A9 — набор А, B1…B11 — набор Б);
- `data/olympiad_data.zip` — всё одним архивом.

Страница публикуется через GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
